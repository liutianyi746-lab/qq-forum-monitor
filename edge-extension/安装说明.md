# QQ频道帖子关键字提醒 · Edge 插件版

命中关键字时，电脑右下角**桌面弹窗**提醒。直接用你 Edge 里已登录的 QQ 频道身份，**不用装 Python、不用任何账号 token**。

> 前提：你需要在 Edge 里登录过 QQ 频道网页版（就是平时用 QQ 扫码登录 pd.qq.com 那样）。插件用的就是这个已有的登录状态，不会再要你为它单独登录一次。

---

## 安装（约 4 步，一次搞定）

1. 打开 Edge，地址栏输入 `edge://extensions` 回车
2. 打开左下角的**「开发人员模式」**开关
3. 点**「加载解压缩的扩展」**，选中这个 `Edge插件版` 文件夹
4. 装好后，点浏览器右上角拼图图标 🧩，把「QQ频道帖子关键字提醒」固定到工具栏

## 使用

1. **先在 Edge 里登录一次 QQ 频道网页版**：访问 https://pd.qq.com/g/iloveswufe 并用 QQ 扫码登录（保持登录即可，不用每次登）
2. 点插件图标，打开小窗口：
   - 填**关键字**（一行一个）
   - **频道**默认 `iloveswufe`，要监控别的频道就填对应的那段
   - 点**「保存设置」**
3. 点**「测试弹窗+接口」**：
   - 会弹出一条「测试通知 ✅」→ 说明弹窗提醒正常
   - 下方会显示「抓到 N 条」→ 说明能正常读到帖子
4. 完成！之后插件会每隔几分钟自动检查，有**新帖命中关键字**就弹窗提醒。点弹窗可直接跳转频道。

> 首次运行会先把当前帖子记下来（不弹窗），之后只提醒新发的、命中关键字的帖子。

---

## 常见问题

- **点测试没弹窗**：Windows 设置 → 系统 → 通知 → 允许 Microsoft Edge 发送通知；Edge 也别开专注/勿扰。
- **提示「没检测到登录态」**：先在 Edge 里访问 pd.qq.com 登录一次。
- **提示登录态过期**：重新访问 pd.qq.com 登录即可。
- **要监控别的频道**：把频道链接 `pd.qq.com/g/` 后面那段填到「频道」框，保存。
- **想手机微信也收到**：在插件窗口的「微信推送 token」框，填上你从 https://www.pushplus.plus/ （微信扫码登录）拿到的 token，保存即可。之后命中会**桌面弹窗 + 微信**双提醒；不填就只桌面弹窗。

## 说明
- 插件只读取你本机 Edge 里 pd.qq.com 的登录态，数据不发往任何第三方，仅本地判断关键字后弹窗。
- 分享给别人：直接把整个 `Edge插件版` 文件夹发过去即可（里面没有任何人的登录信息，各自用各自 Edge 的登录态）。
