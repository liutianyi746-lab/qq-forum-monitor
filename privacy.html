隐私政策 · QQ频道帖子关键字提醒

最后更新：2026-07-27

本扩展（“QQ频道帖子关键字提醒”，以下简称“本扩展”）是一个供用户个人使用的工具，帮助用户监控其自己有权访问的 QQ 频道帖子，并在帖子包含用户设定的关键字时在本机弹出提醒。本政策说明本扩展如何处理数据。

一、本扩展访问的数据

  • 登录态（Cookie）：本扩展读取你浏览器中 pd.qq.com 域下的登录 Cookie（如 p_skey），仅用于在你本机向 QQ 官方接口发起请求、以你的身份获取你有权查看的帖子列表。本扩展不会上传、存储或分享该 Cookie。
  • 帖子内容：从 QQ 接口返回的帖子标题、正文、作者，仅在你本机内存中用于关键字匹配，匹配后仅保留帖子 ID 用于去重（存于浏览器本地存储）。
  • 你的设置：关键字、频道标识、检查间隔、以及可选的 PushPlus 推送 token，保存在浏览器本地存储（chrome.storage.local），不会上传至开发者或任何第三方。

二、数据发往何处

  • 默认情况下，本扩展不向任何第三方服务器发送数据。所有关键字判断都在你本机完成，命中时通过浏览器本地通知提醒。
  • 与 QQ 服务器（pd.qq.com）的通信，仅为获取你自己有权查看的帖子，等同于你在浏览器中浏览该频道。
  • 可选：仅当你主动填写了 PushPlus token，本扩展才会在命中关键字时，将命中的帖子标题/摘要发送至 PushPlus（pushplus.plus）以推送到你的微信。是否使用完全由你决定，不填则不发送。

三、数据不用于什么

本扩展不收集个人身份信息用于分析或广告，不出售数据，不进行用户画像，开发者无法访问你的任何数据。

四、权限说明

  • cookies + host_permissions: pd.qq.com：读取登录态以你的身份获取帖子。
  • storage：保存你的设置与已提醒记录。
  • alarms：定时检查新帖。
  • notifications：命中关键字时弹出桌面提醒。
  • host_permissions: www.pushplus.plus：仅在你配置了 token 时用于推送到微信。

五、数据删除

卸载本扩展即删除其在浏览器本地存储的全部设置与记录。你也可在扩展设置中清除数据。

六、联系方式

如有疑问或需要反馈，请在项目的 GitHub Issues 中提出。
