# QQ 频道帖子关键字监控 —— 使用说明

盯着某个 QQ 频道，帖子里出现你设的关键字时，自动推送到你的微信。

---

## 准备工作（各做一次）

### 1. 装 Python
如果电脑没装过 Python：去 https://www.python.org/downloads/ 下载安装，
**安装时务必勾选「Add Python to PATH」**。

### 2. 拿一个 PushPlus token（用来收微信通知）
1. 打开 https://www.pushplus.plus/
2. 右上角「登录」→ 微信扫码
3. 进入「一对一推送」，复制你的 **token**

### 3. 填配置
用记事本打开 `config.yaml`，改两处：
- `pushplus_token`：粘贴你上一步的 token
- `keywords`：改成你想监控的关键字
- （可选）`channel_url`：换成你想监控的频道链接

---

## 开始使用（按顺序双击）

| 步骤 | 双击这个文件 | 作用 |
|---|---|---|
| 第1步 | `第1步_安装依赖.bat` | 装运行环境（只需一次） |
| —— | `测试推送.bat` | 测一下微信能不能收到（收到再往下） |
| 第2步 | `第2步_扫码登录.bat` | 弹浏览器扫码登录 QQ 频道，看到帖子后回车 |
| 第3步 | `第3步_开始监控.bat` | 开始监控，保持窗口开着即可 |

启动后会先静默记录当前帖子，**之后有新帖命中关键字才推送**。关机后要重新双击第3步。

---

## 常见问题

- **双击 bat 一闪就没了 / 提示找不到 python**：说明没装 Python 或没勾 Add to PATH，重装 Python 并勾选。
- **收不到推送**：先跑 `测试推送.bat`；确认 `config.yaml` 里 token 填对。
- **提示登录态过期**：重新双击 `第2步_扫码登录.bat`。
- **要监控别的频道**：改 `config.yaml` 的 `channel_url`，然后重新跑第2步。

## 注意
- 本工具用你**自己的** QQ 登录态、**自己的** PushPlus token，仅供个人监控，请勿高频使用。
- 运行后会生成 `request_template.json`（含你的登录态）、`browser_data/` 等文件，**这些属于你的隐私，不要转发给别人**。
